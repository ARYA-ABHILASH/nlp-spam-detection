# SMS Spam Detection Using NLP and Machine Learning

## Project Overview
This project classifies SMS messages as Spam or Ham (legitimate messages) using Natural Language Processing (NLP) and machine learning techniques.

## Tools and Libraries
- Python
- Pandas
- Regular Expressions
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Google Colab

## Project Objectives
- Clean and preprocess SMS messages.
- Convert text into numerical features using TF-IDF.
- Train a machine learning classification model.
- Evaluate the model using accuracy, precision, recall, and F1-score.
- Predict whether new messages are spam or legitimate.

## Model Performance
- Accuracy: 97.10%
- Spam Precision: 99%
- Spam Recall: 78%
- Spam F1-score: 0.87

## Key Learnings
- Text preprocessing
- NLP fundamentals
- Text vectorization using TF-IDF
- Machine learning classification
- Model evaluation
